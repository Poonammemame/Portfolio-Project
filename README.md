## 🛠️ Built With

- **HTML5:** Semantic structure (`header`, `nav`, `main`, `section`, `footer`)
- **CSS3:** Custom properties (CSS variables), responsive flexbox/grid, transitions, dark/light mode
- **Bootstrap 5:** Mobile-first 12-column grid system, utility classes, responsive navbar, modals, and toasts
- **Bootstrap Icons:** Official vector iconography
- **Vanilla JavaScript:** 100% dependency-free custom JS (live typing loop, theme toggle with `localStorage`, active scroll tracking, category filtering, certificate modal preview, toast alerts, and client-side contact validation)
